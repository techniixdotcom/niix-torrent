NiiX Torrent
============

Overview
--------

NiiX Torrent is a tiny BitTorrent client for Windows and Linux. It is written in C++ using
Rasterbar-libtorrent and wxWidgets.

.. note:: In case you find errors in this documentation you can help by sending
          `pull requests <https://github.com/techniixdotcom/niix-torrent>`_!
